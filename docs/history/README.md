# Historical material

根目录 `old/` 保存旧对话和旧 handoff。其作用是：

- 追溯定义来源；
- 保存反例与失败路线；
- 复核历史计算；
- 防止同一错误以新术语重现。

## Reading rule

每份历史材料应通过当前 `FACTS.md`、`FAILURES.md`、`QUESTIONS.md` 和
`docs/PROOF_DAG.md` 解释。历史文件中的中途突破、临时假设和最终纠错可能同时存在。

最新对话 `chatgpt-export_深度二分析执行.txt` 尤其包含多次范围纠正。规范净结论见：

- `docs/ledger/PROGRESS.md`
- `docs/framework/FW-40_FUTURE_COMPLETE_LIFT.md`
- `HANDOFF_CURRENT.md`

不得从该对话中单独摘取“Q-0016/17 已证明”的中途回答。
