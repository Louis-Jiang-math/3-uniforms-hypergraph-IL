# FW-30 — Pivot-switch and escape

- **Status:** proved-conditional / proved-formal
- **Questions supported:** Q-0015, Q-0016
- **Normative detailed source:** root `PIVOT_SWITCH_ESCAPE_FRAMEWORK.md`

## Contract

### Input

实际可达单缺陷执行记录、真实第一 blocker、完整 genealogy 和 global edge ledger。

### Output

- combinatorial pivot-switch；
- actual reroot lift 判据；
- switch/multi-defect escape incidence；
- finite Hall full-flow 或 Hall/reuse cut；
- formal closure-or-charge。

## Proved

- 静态 switch 方块的组合性质；
- 真实 reroot lift 的必要执行路径；
- 有限 escape obligations 的 real-edge Hall 二分；
- 在已支付 escape 质量移除后，剩余 ordinary 活动质量保持同一 pivot/projection/单缺陷形式；
- 条件 \(11/27\) 森林摊还。

## Nonclaims

- formal closure-or-charge 不是近无损动态 closure；
- Hall 可支付不说明费用集中；
- incidence 增殖不推出 \(1/4\) 或完整子核心；
- switch 不提供免费新根预算。
