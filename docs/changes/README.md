# Change manifests

For every substantial repository write, create `YYYY-MM-DD-<slug>.md` before the first mutation.

Required fields:

```text
Base commit:
Write mode:
Task:
Target DAG node:
Allowed paths:
Forbidden paths:
Claim status sought:
Acceptance criterion:
Required validations:
Final status: draft | validated | rejected
```

The manifest records scope and validation. It is not evidence that a mathematical claim is true.

- `2026-08-06-fork-inverse-fiber-route.md`: active-route change, F-0078 scope correction, and Q-0019.
- `2026-08-08-q0019-rank-two-zipper.md`: Q-0019 common-parent rollback, pair grammar, normal-Q4 zipper/support geometry, and current rank-two support-return frontier.
