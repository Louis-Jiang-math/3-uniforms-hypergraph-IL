# Canonical knowledge registries

This directory contains the current, stable project registries.

- `knowledge/FACTS.md`: statements that may be cited, with scope and evidence status;
- `knowledge/FAILURES.md`: counterexamples, unsupported assumptions, and failed mechanisms;
- `knowledge/QUESTIONS.md`: open and answered questions with completion criteria;
- `DECISIONS.md`: active methodological and architectural decisions;
- `DEFINITIONS.md`: entry point for notation and object types.

Full arguments, code, experiments, and audits belong under `evidence/`, `src/`, `tests/`, and `docs/framework/`. Raw conversations are not canonical knowledge.
