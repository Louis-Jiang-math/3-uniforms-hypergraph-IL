# Q-0019 combinatorial-compression audit — 2026-08-08

## Purpose

The supplied conversations explored many increasingly specific descriptions of
the one-coordinate/high-overlap residual.  This audit separates **real
combinatorial compression** from relabelling.  It is intentionally broader than
the current normal-zipper route so that useful negative information is not lost.

A step counts as a genuine compression only if it demonstrably reduces at
least one of:

1. the number of free source coordinates/states;
2. the arity or sustainable branching of the genealogy;
3. an actual resource controlled by degree/codegree/support capacity;
4. a source-owned monotone or telescoping potential.

A smaller name for the residual is not a compression.

## Superseded intermediate frontiers

Several frontiers were useful because they exposed the next failure, but should
not remain as the current target:

1. **persistent-anchor extraction from one local heavy coordinate** — too
   strong; local heavy objects migrate;
2. **global irreversible peg** — stronger than necessary and not established;
3. **protected-handoff geometric contraction** — analytically attractive, but
   state semantics and child double counting were unresolved;
4. **support synchronization along a cylinder** — superseded by exact parallel
   rollback;
5. **strict endpoint persistence** — directly false in normal Q4;
6. **instantaneous `P^2 -> P` from a splice** — stronger than what confluence
   proves.

The current useful weakening is: finitely many source-static normal supports
may be consumed for free; subsequent return must force actual-edge reuse or an
exact future merge.

## Results from the supplied older proof-gap conversation that remain design constraints

The older conversation repeatedly arrived at the same meta-obstruction through
different local graphs, switch planes, and entropy variables: a local
high-overlap residual can be described very finely without reducing source
mass.  The following conclusions remain valuable even where the intermediate
notation has been retired:

- the high-overlap regime is essentially repeated one-coordinate/pair reuse,
  not a failure of the local `b^{-2}` output count;
- a full two-dimensional switch plane is more informative than following one
  reset path, but it must be tied to source ownership before producing a charge;
- a finite transition graph or potential is an organizer, not an automatic
  degree bound;
- new entropy at every restart is not a telescoping source budget;
- any proposed `o(1)` high mark must be checked against the actual pair record
  language to exclude charging an already-existing child;
- after all descriptive reductions, progress must come from actual capacity,
  exact obligation cancellation, or a source-owned return potential.

These principles are now encoded in the Q-0019 route rather than preserved as
separate migration subtypes.
